# 📚 Referência Rápida de Programação

Coleção pessoal de documentações oficiais, cheatsheets e guias de bolso para consultar sintaxe sem perder tempo.

> **Regra de ouro:** cheatsheet para relembrar, documentação oficial para confirmar.
> Para recursos novos da linguagem ou comportamento exato de uma função, confira sempre a doc oficial ou o DevDocs.

## 💻 Consulta pelo terminal

```bash
# tldr: exemplos práticos de um comando
npm install -g tldr      # ou: pip install tldr
tldr tar
tldr docker run

# cheat.sh: sem instalar nada (manutenção baixa, use como apoio)
curl cheat.sh/tar
curl cheat.sh/php/array_map
curl cheat.sh/python/list+comprehension
curl cheat.sh/js/fetch

# Docs nativas
man grep                 # manual completo
grep --help              # resumo das opções
python3 -m pydoc str     # documentação de módulos e tipos Python
php --rf array_map       # assinatura de uma função PHP
```

```
.
├── README.md          # este índice
├── notas/             # anotações próprias por linguagem (php.md, python.md...)
└── snippets/          # trechos de código reaproveitáveis
```

> Dica: quando aprender algo que vive esquecendo, anote em `notas/<linguagem>.md`. Com o tempo vira um cheatsheet feito sob medida.
